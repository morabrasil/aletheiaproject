# aletheia project

A library of public-domain philosophy: works read in their original language, browsed by period, author and work, with an English and Portuguese interface, reference pagination in the margin and copy-as-citation (ABNT, APA, Chicago, MLA).

Status: prototype, with short excerpts from each work and indicative reference pagination.

The site is static: serve `index.html` (GitHub Pages or Cloudflare Pages).

## Texts and licenses

- Plato: Greek text of J. Burnet's *Platonis Opera* (Oxford), digitized by the Perseus Digital Library, CC BY-SA 4.0. See `data/plato/README.md`.

# aletheia project

Biblioteca de filosofia em domínio público: obras lidas na língua original, com navegação por período, autor e obra, interface em português e inglês, paginação de referência na margem e cópia formatada como citação (ABNT, APA, Chicago, MLA).

Estado atual: protótipo, com trechos curtos de cada obra e paginação de referência indicativa.

O site é estático: basta servir o `index.html` (GitHub Pages ou Cloudflare Pages).
